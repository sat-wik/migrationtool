## Claude's discretion settled here (record each in the SUMMARY)

- New roles (additive; `ArgRole` gains `mutable: bool`, `values: Vec<String>`, `of: Option<String>`):
  - `inout_len`: pointer to an integer; `name`, `default` and optional `sweep` (the declared initial values, a combination dimension); `of = "out"` makes it the capacity of the entry's out_buf (then no out_cap). Recorded typed in lib_state_in (initial) and lib_state_out (after).
  - `out_scalar`: pointer to a scalar or enum; `name`; zero-filled in its own guarded mapping; recorded in both lib_state objects.
  - `out_ptr`: pointer to a pointer; `name`; zero-filled; recorded classified (null, a region offset, a symbol, or unobserved).
  - `str` with `str_len`: `str` needs `name` and `values` (1 to 8 strings of printable ASCII 0x20..0x7E, at most 64 bytes each; a combination dimension); `str_len` takes `of = "<str name>"` and is derived (the byte length, without the NUL). The bytes travel in the request file into a guarded mapping with a trailing NUL; argv carries the string as text.
  - `in_buf` with `mutable = true`: the input bytes after the call are recorded as lib_state_out `in` (hex); only allowed when the parameter type has no `const` on its pointee.
- Return kinds from the signature's return text: integer or enum (including `_Bool`, `size_t`) to rc as a 32-bit signed reinterpretation; `void` to 0; a pointer to rc 0 or 1 plus `ret` classified like any pointer (and the heap walk from it); a struct or union by value (no `*`, not a known integer or `void`) to rc 0 plus `ret` decoded with the LayoutModel from the probe (one probe global of the return type).
- Heap walk (`walk_heap`): the driver dumps the arena's used bytes (from its fixed base up to the `_sbrk` high-water mark) as a frame region; roots are every recorded pointer classified into `heap`; an edge is a pointer field whose pointee type is a struct, union, array or scalar, decoded at its offset if it fits inside the used bytes; a `char` (or signed or unsigned char) pointee is the NUL-terminated byte run in hex; keys are decimal offsets; visited offsets are not decoded twice; at most `HEAP_WALK_CAP = 4096` objects, and pointers beyond the cap become unobserved with the reason `heap walk cap reached`. A `void *` into the heap stays a classified pointer with no object (no type to decode).
- Initial roles, each with a comment naming the decisions:
  - zlib `uncompress (Bytef *, uLongf *, const Bytef *, uLong)`: out_buf; inout_len `destLen` with `of = "out"`, `default = 256`, `sweep = [16, 4096]`; in_buf; in_len.
  - paho `MQTTDeserialize_connack (unsigned char *, unsigned char *, unsigned char *, int)`: out_scalar `sessionPresent`, out_scalar `connack_rc`, in_buf, in_len.
  - paho `MQTTDeserialize_publish (unsigned char *, int *, unsigned char *, unsigned short *, MQTTString *, unsigned char **, int *, unsigned char *, int)`: out_scalar `dup`, out_scalar `qos`, out_scalar `retained`, out_scalar `packetid`, state `topicName`, out_ptr `payload`, out_scalar `payloadlen`, in_buf, in_len.
  - nanopb `pb_istream_from_buffer (const pb_byte_t *, size_t)`: in_buf, in_len; struct return.
  - cjson `cJSON_ParseWithLength (const char *, size_t)`: in_buf, in_len; pointer return (heap walk of the cJSON tree); its writable global `global_error` typed by plan 03-05.
  - corejson `JSON_SearchT (char *, size_t, const char *, size_t, char **, size_t *, JSONTypes_t *)`: in_buf `mutable = true`, in_len, str `query` with a few values chosen from the seeds' common keys (for example `a`, `name`, `0`; record the choice), str_len `of = "query"`, out_ptr `outValue`, out_scalar `outValueLength`, out_scalar `outType`.
- Adapter drop log `testbed/adapter-dropped.toml`, the `testbed/dropped.toml` pattern: `schema_version = 1`, header comment naming D-13 and D-28, `[[dropped]]` with `target`, `entry`, `cause`, `detail`, `attempt` (never empty; `none: the seed corpus lists no seed for this entry (D-28)` for no_seeds) and optional `ci_run`. Causes: `no_seeds`, `not_expressible`, `link_unresolved`, `attempt_failed`, `nondeterministic`, `not_attempted` (an entry left unattempted at a phase budget stop under D-24; its `detail` is `phase budget (D-24)` and its `attempt` is `none: stopped at the phase budget before the attempt`). An entry is in the log or has roles, never both. This plan logs the three no_seeds entries and leaves the rest of the not-yet-attempted entries to plans 03-07 and 03-08 (they have neither roles nor a log row yet, and the floor test does not count them).
- `drivable_targets(manifest, seeds_dir, phase2_drops, adapter_drops)`: a target counts when it is retained by the Phase 2 drop log and has at least one entry with roles, at least one seed whose index lists that entry, and no adapter drop row. `ADAPTER_FLOOR = 10` (equal to `MIN_RETAINED`; no option lowers it).
