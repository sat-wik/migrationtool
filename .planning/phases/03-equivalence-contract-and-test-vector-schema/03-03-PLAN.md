## Claude's discretion settled here (record each in the SUMMARY)

- Two validation levels (research Q1 point 7):
  - Reference level, `Vector`: all eight non-has_ub fields required, `#[serde(deny_unknown_fields)]` (so `note` and `lib_state` are rejected), `env` empty, `is_regex` false, `argv[0]` matching `^[a-z0-9][a-z0-9_-]*/[a-z0-9][a-z0-9-]*/[A-Za-z_][A-Za-z0-9_]*$`, `stdin` and `stdout.pattern` Latin-1 decodable, `stderr.pattern` starting `outcome=<class>` with a class in `OUTCOME_CLASSES`, `has_ub` absent or a `HasUbLabel` matching `^[a-z][a-z-]*(:[A-Za-z0-9_.-]+)*$`.
  - TRACTOR level, `TractorVector`: every field optional as in cando's `TestVector` (`argv`, `stdin`, `env`, `stdout`, `stderr`, `rc`, `lib_state_in`, `lib_state_out` as free JSON, `has_ub`, `note`), `deny_unknown_fields`; `has_ub` is deserialized with a `deserialize_with` function so a present `null` is kept as present.
- "Loads unchanged" means: parsed with no preprocessing, then re-serialized to a `serde_json::Value` equal to the parsed file's `Value` (research Q1 point 8: serde_json maps are sorted, so the file's bytes and key order are not preserved; never promise byte equality for TRACTOR files). Our own vectors are byte-identical on re-serialization.
- Canonical JSON for our vectors: `serde_json::to_vec_pretty` of the struct in field order, maps as `BTreeMap`, plus a trailing newline. `Vector::sha256` is the sha256 of those bytes and is the file name.
- Size and depth caps: a vector file above 16 MiB is refused before parsing (`MAX_VECTOR_BYTES`); serde_json's default recursion limit stays on.
- `OutcomeClass` (`ok`, `fault`, `abort`, `timeout`, `setup_failed`) lives in mt-vectors as the schema's source of truth; plan 03-04 ties mt-harness's `Outcome::class_word` to it with a test.
- Corpus layout per (target, config, entry): `<dir>/<sha256>.json` and `<dir>/index.json`; the index is `CorpusIndex { schema_version: 1, target, config, entry, vectors: BTreeMap<sha256, Provenance> }`, the `mt-seeds::index` pattern. `write_corpus` takes the whole set at once (the executor holds the vectors in memory until every run finished), requires the directory to be absent or empty, writes, then lists the directory and fails with `CorpusError::Tampered` on any entry it did not write; `read_corpus` refuses symlinks, non-regular files, names that are not 64 lowercase hex plus `.json`, and files above the cap.

## CI round trip (protocol of plans 02-17..02-22 with the orchestrator's push rule; stated here in full)

1. Commit. Push only when `git rev-parse --abbrev-ref HEAD` prints `claude/gsd-discuss-phase-1-mzdw5v`, and only with `git push -u origin claude/gsd-discuss-phase-1-mzdw5v`. Never force, never push main, never rebase, never open a PR, never create or push another branch. On a network failure retry the same push up to 4 times, waiting 2 s, 4 s, 8 s and 16 s; then stop and report.
2. `SHA=$(git rev-parse HEAD)`; list its runs with `gh api "repos/sat-wik/migrationtool/actions/runs?head_sha=${SHA}&per_page=50" --jq '.workflow_runs[] | [.id, .path, .status, .conclusion] | @tsv'`.
3. Poll every 60 s (one Bash call is limited to 10 minutes) until the awaited runs are `completed`. A run still going 15 minutes after its `timeout-minutes` is stuck: stop and report.
4. Jobs: `gh api repos/sat-wik/migrationtool/actions/runs/<run_id>/jobs --jq '.jobs[] | [.id, .name, .conclusion] | @tsv'`.
5. Annotations: `gh api --paginate repos/sat-wik/migrationtool/check-runs/<job_id>/annotations --jq '.[] | "== " + .title + "\n" + .message'`. Join the parts of one title with a newline, in order. GitHub keeps 10 annotations per level per step; a missing title means the step must be split, never that it passed.
6. Evidence comes only from `gh api repos/sat-wik/migrationtool/actions/...` and check-run annotations; log and artifact hosts are blocked and there is no local Docker. Any `gh api` failure: stop and report, asking the founder to paste the job conclusions and annotation text. A missing run, a skipped job or an unreadable result is never green and does not count as a round trip.
