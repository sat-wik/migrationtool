- Placeholders: `{cc}` = the pinned arm-none-eabi-gcc path; `{cflags}` = baseline cflags, then the configuration's `-D` defines and its cflags, in that order; `{src}` = absolute source root of the run; `{inputs}` = absolute directory holding the committed files under `testbed/targets/<id>/`.
