<objective>
Close G-02-3. Narrow the declared seed sources of httpparser, nanopb and qcbor to the test arrays and fixture files that hold parser inputs (founder decision, UAT test 4), so error messages, labels and identifiers stop entering their corpora. httpparser needs a finer selector than a file path because all its inputs and all its noise share test.c, so seed sources gain an optional `designators` list (the `.raw` member of its message arrays).

Purpose: the seeds the Phase 3 and Phase 5 harnesses start from are inputs, not text from the test harness.
Output: lexer function, manifest field and validation, seeding wiring, narrowed manifest tables, regenerated corpora for the three targets.
</objective>
