## Founder decisions (G-02-8 in 02-UAT.md, binding)

1. Replace the deny-list gate with an allow-list gate built on one operand-aware argument walk. The walk knows which options take a separate operand, so an operand is never read as an option. ## Claude's discretion (planner choices; record each in the SUMMARY)

Cause taxonomy. The allow-list decides; no list of known-bad options is kept for naming. Table: refusal, then `CcError`, then cause token.
- empty argv: `NotCompileOnly`, `not_compile_only` (unchanged)
- argv[0] not allow-listed: `CompilerNotAllowed`, `compiler_not_allowed` (unchanged)
- any argument after argv[0] that starts with `@`, operand or not: `HelperOption { flag }`, `helper_option` (kept: the driver reads options from a file)
- `-specs=<name>` with a name not in `SHIPPED_SPECS`, empty, or containing `/`, and every other argument that starts with `-specs`: `HelperOption { flag }`, `helper_option` (kept: the driver reads commands from a spec file)
- `-flto*` and `-fprofile-*` options: `ForbiddenFlag { flag }`, `forbidden_flag` (unchanged; regression guard)
- any other argument that starts with `-` and is not on the allow-list (every `--<name>`, every carrier, `-wrapper`, `-B`, `-fplugin*`, `-include`, `-x`, `-dumpdir`, and so on): new `OptionNotAllowed { flag }`, new token `option_not_allowed`
- trailing `-o`: `DanglingOutput`, `dangling_output` (unchanged; regression guard)
- trailing `-MF`, `-MT` or `-MQ`: `WriteRedirect { flag }`, `write_redirect` (kept: an unboundable depfile)
- trailing `-I`: `OptionNotAllowed { flag: "-I" }`, `option_not_allowed`
- an `-o` or `-MF` operand that resolves (lexically, against the entry's directory) outside the run root, or a directory or derived output outside it: `OutsideRunRoot { path }`, `outside_run_root` (unchanged)
- no top-level `-c` after a complete walk: `NotCompileOnly`, `not_compile_only`
