# Phase 1 Plan 07: Container image and CI proofs Summary

**A seven-stage Dockerfile that builds clang/LLVM 16, KLEE 3.2 with klee-uclibc, c2rust 0.22.1, Bear, cargo-mutants, two rustc toolchains, Arm GNU 14.3.rel1 and QEMU from sha256- and commit-verified inputs, proven in GitHub Actions: `mt toolchain check` exits 0 inside the image with no network, an LLVM-17 pins copy exits 1, two independent builds give a byte-identical manifest, and the no_std smoke crate builds for thumbv7em-none-eabihf next to arm-none-eabi GCC.**
