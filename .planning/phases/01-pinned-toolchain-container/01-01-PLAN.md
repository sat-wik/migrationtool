## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mt process -> analyser subprocess | Every external tool is launched here; parent env, argv and tool output cross this line |
| pins file -> mt | pins.toml supplies paths, argv and regexes the runner and check consume |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Information disclosure | runner.rs env handling | high | mitigate | `env_clear()` then fixed base plus named extras only; tool_01_runner_clears_environment_and_applies_fixed_base asserts parent variables are absent |
| T-01-02 | Elevation of privilege | runner.rs argv | high | mitigate | argv is `Vec<OsString>` passed directly to the OS; no shell string interpolation anywhere in mt-toolchain |
| T-01-03 | Denial of service | runner.rs stream capture | medium | mitigate | per-stream cap (16 MiB default) with streaming hash; tool_01_runner_caps_output_without_deadlock |
| T-01-04 | Denial of service | runner.rs wait loop | medium | mitigate | mandatory timeout, kill on expiry, bounded 5 s drain; timed_out recorded and never treated as success |
| T-01-05 | Denial of service | check.rs regex from pins | low | mitigate | RegexBuilder size limit 1 MiB; Rust regex is linear-time |
| T-01-SC | Tampering | cargo dependency installs | high | mitigate | only crates listed Approved in 01-RESEARCH.md Package Legitimacy Audit, exact versions, Cargo.lock committed; c2rust (SUS) is gated by plan 01-02 before any install |
