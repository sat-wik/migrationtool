## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pins.toml -> mt-toolchain | hand-edited pins feed paths, URLs, digests and regexes into the build and the check |
| tool output -> parsers | version text from tools is untrusted input to regexes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-08 | Tampering | pins.rs parsing | high | mitigate | deny_unknown_fields everywhere; validate rejects malformed hex, digests, non-https URLs and placeholders (tool_03_pins_* tests) |
| T-01-09 | Tampering | build_args.rs rendering | medium | mitigate | values with whitespace, newline or NUL rejected so a pin cannot inject an extra build argument; output sorted |
| T-01-10 | Denial of service | version.rs regex compile | low | mitigate | RegexBuilder size limit 1 MiB; linear-time engine |
| T-01-SC | Tampering | cargo dependency installs | high | mitigate | no new crates in this plan; c2rust legitimacy gated by plan 01-02 |
</threat_model>
